# STEER Guidebook

_Framework v3.1 · one operational canon_

The Guidebook is the reading map for the STEER canon. It does not duplicate the source documents: each entry opens the versioned source page used by both the platform and the agent fleet.

## Start with why

Read the Methodology for the constraint shift, Agile values re-implemented for agent labor, the five moves, and STEER's governing principles.

## Learn the structure

Read the Framework for the artifact chain, three surfaces, eight plays, three gates, measurement, sizing, and scoping.

## Understand how organizations run it

Read the Operating Model for the organization topology, solo-mode hats, agent identities, trust-metered autonomy, personal capacity, Stack Packs, readiness, handover, isolation, agent-first onboarding, culture, scale, governance, adoption, and protected attention.

## Use the practice notes

The numbered practice notes provide the daily operating detail for sizing and scoping, providing intent, and the three surfaces.

## Speak the same language

Use the Glossary for the shared definitions behind intent, pull, work item, exam, gate, band, outcome contract, and risk-domain routes.

## About the public whitepaper

The public Whitepaper is intentionally outside this operational canon. Its external location has not been configured in this repository; the hub does not invent or cache a copy.
