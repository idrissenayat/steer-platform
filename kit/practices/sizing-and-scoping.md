# Sizing and scoping

STEER sizes ambiguity, not agent effort. Story points and developer-hour
capacity are not commitments or reporting units.

## Frame check

A brief is ready to approach Gate 1 when it has one outcome, one crisp exam,
and one coherent shape. If the exam cannot be written concretely, split at a
user path, domain tag, interface seam, or legacy on-ramp before the gate.

## Engineer check

A plan that reaches the configured file or system threshold raises a
plan-sprawl alarm. Split the work; do not expand the signed exam. Scope freezes
at Gate 1, so a new want is either a gated revision or a new brief.

## Aging and forecasting

Each Flight Board state uses a cycle-time band derived from pod history. A band
breach escalates to a huddle. Forecast initiatives from the 85th-percentile
cycle time for comparable brief shapes. Put a real deadline in the brief as a
constraint, not as an estimate.

Capacity is counted per human across every pod and accountability hat they
hold. A pull is refused when it would exceed that person's declared attention
budget; moving the same person to another pod does not create new capacity.
