# Development acceptance

Not a protected Exam, fresh-context Critic or gate decision.

- Sub-millisecond future, reversed, session-inconsistent and prerequisite-invalid
  input cannot satisfy normalized gate policy.
- A genuinely ordered nanosecond Critic/authentication/signing sequence passes
  the same normalized rules; equality still fails strict post-Critic checks.
- Every gate timestamp field rejects malformed calendars/excess precision.
- Equivalent fractions preserve one session; result remains ordinary JSON with
  source verification required.
- Parser tests cover fractional widths, invalid input, UTC calendar boundaries,
  pre-epoch nanoseconds, leap years and four-digit-year endpoints.
- Focused checks and the complete repository verification pass without protected
  changes, new provider access or write activation.
