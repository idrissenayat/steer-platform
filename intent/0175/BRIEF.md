# Brief

## Problem

The fixed recorded-Brief client has owned recovery but no canonical current-caller
authorization boundary. A projection/Brief-save grant must not silently authorize
dispatch, and a workflow reference must never act as permission.

## Proposed outcome

Shared exact-operation start/status tools enforce separate grants and current
identity, use the existing structural client port, and expose consistent HTTP/MCP
contracts without activating live scheduling or new source admission.

## Boundaries

No new live grant/profile, Git save, gate proof, protected edit, spending, deployment,
release or real deletion. All five R5 findings and human/independent reviews remain.
