# Development specification

1. Mount a read-only existing-scope section within the actual intent composer.
   Bind its repository from the existing gateway-verified page display hint.
2. On explicit check, call only `intent.overlap.check` using the existing bounded
   HTTPS same-origin cookie transport. No model invocation, save or auto-retry.
3. Verify returned organization, repository and exact original-text fingerprint.
   Reject malformed, foreign, late and counterfeit-clearance responses.
4. Render matching source passages as inert text, with path/revision and lexical
   uncertainty. Expose catalog/inspection counts, gaps and scan/result limits.
   An empty/failed search cannot say the intent is new.
5. Open an existing Brief using the canonical exact-revision fragment reader.
   Spec matches must link with the Brief digest, never the Spec digest.
6. Input or scope changes invalidate displayed results; hidden/expired/unmounted
   owners abort and clear retained references. Preserve the original composer text.
7. Missing repository configuration disables search with an explanation. Do not
   add grants, infer read access, simulate source results or activate model spending.
8. Semantic judgments, explicit disposition and mandatory pre-save duplicate checks
   remain separate pending work; this is the source-inspection UI.
