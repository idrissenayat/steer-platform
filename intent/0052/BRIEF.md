# Brief

The interface and platform agent need to discover Briefs they may read rather
than asking a human to type source paths and revision fingerprints. Add a
catalog limited to the runtime's already-curated Brief paths and projected data.

Do not expose unrelated files, content, fabricated titles/statuses or a second
system of record. Preserve current authorization and restricted database roles;
return a complete bounded set that can feed exact-revision Brief reads.
