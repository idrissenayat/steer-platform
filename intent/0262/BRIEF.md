# 0262 — Request the preserved candidate save

People who have confirmed an exact package need an explicit way to request its
authorized repository save in the actual application. Preservation is not save
consent, a scheduler acknowledgement is not a Git commit, and uncertainty must
never create a replacement operation.

Connect the prepared original to the existing reference-only save workflow while
preserving current human, source, records and publication authority. Do not activate
real providers, change signed artifacts, adopt D1, authorize spending or bypass auth.
