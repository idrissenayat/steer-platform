# Development acceptance

Not a protected Exam or independent gate record.

- Exact regenerated confirmation, originator, canonical target and expected head
  bind the operation; supplied authors, gate claims and noncanonical paths deny.
- Existing malformed/ambiguous/missing-fact drafts cannot enter write I/O.
- Current human and all required grants are checked at each pre-dispatch boundary.
- Trusted authority pins and freshness cannot be substituted, expired or rounded.
- Duplicate/concurrent synthetic submissions commit once; changed-key payloads
  conflict. A moved branch never triggers blind rebase or force.
- Unknown inspection never becomes absence; lost acknowledgement and post-dispatch
  revocation do not produce a false failed/rolled-back/success claim or a new write.
- Returned commit/blob/content/request metadata must exactly match the request.
- Default API/MCP save and readback remain unavailable without the trusted writer;
  default startup still denies unauthenticated access.
- Repository checks pass; no protected artifacts or provider permissions change.
- Evidence explicitly distinguishes the synthetic port from missing actual
  GitHub atomicity, durability, source authority, Gate 2 and UI activation.
