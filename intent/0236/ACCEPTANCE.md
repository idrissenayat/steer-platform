# Acceptance boundary

Recovery must return the exact originally captured scope/corpus/profile and manifest,
including a multi-part corpus larger than the single-document bound, without storing
Exam or plaintext in metadata. Races/lost acknowledgement preserve one immutable
row. Current ownership, source permission, records policy, keys and lifecycle govern
release; expiry and later edits cannot enable another execution.

Only disposable PostgreSQL uses the new migrations. Synthetic grants, profile
approvals, keys and lifecycle owners are test fixtures, not activated services.
This acceptance record is neither the canonical Exam nor a gate signature. Original
recovery alone does not prove a completed semantic review, result recovery or UI journey.
