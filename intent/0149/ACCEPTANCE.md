# Development acceptance

- Authoring embeds the destination check without changing draft facts or preview.
- Only a user-initiated, same-origin, authenticated read request is made.
- Wrong tenant, output, authority claims, stale/future time and access errors clear details.
- Refresh, hiding, expiry, replacement and closure suppress late data and old timers.
- The observed branch revision never becomes permission or a save argument.
- Status text and native controls are present; the existing palette is preserved.
- Component markup, controller, architecture, type and full checks pass.
- Browser/manual accessibility and real configured journey evidence are not fabricated.
