# Brief — Recorded intent editor journey

The user needs the actual platform to turn freely expressed intent into reviewed,
editable documents reliably. Existing prepare/start/read services are insufficient
while the editor still uses only the older one-shot generation path.

Connect the production conversation and draft controls to the recorded workflow.
Preserving and reviewing an intent should be one explicit action. Source review
must expose complete context and gaps, not infer semantic newness. Human direction
is bound to exact draft and repository snapshots; generation and result application
remain deliberate. Recover lost responses without duplicate paid dispatch, and
never replace newer human text with late results.

Real records activation, provider/corpus authority, semantic assessment, paid model
tests and GitHub publication are separate unresolved requirements, not granted here.
