# 0266 — Existing-item destinations and explicit direction routing

The actual intent journey must revise an unpulled candidate without losing its
exact parent, and prepare an amendment for canonical/in-flight work without
overwriting canonical documents. Implement repository verification under mandatory
current lifecycle policy and compose it with the existing new-item resolver.

Preserve exact human direction, source fidelity and existing relationships.
Do not infer lifecycle, silently replace a selected proposal, create live authority
or mistake native synthetic tests for signed-in acceptance.

Scope: verified candidate revisions and first amendment destinations. Record and
keep closed the discovered current-review versus immutable proposal-target mismatch.
See [process guide](../../docs/EXISTING-CANDIDATE-DESTINATION.md),
[specification](SPEC.md) and [evidence](EVIDENCE.md).
