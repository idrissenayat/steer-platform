# Brief

Before the first real GitHub save, source-backed gate review requires provenance
as well as consistent report content. Existing native domain records retain a
reviewer's identity and fresh-context declaration but do not authenticate the
execution that produced the exact bytes.

Implement an internal, disabled-by-default runner-receipt verification contract
and its actual Git-source composition. Preserve all original records, findings,
open R5 obligations and the closed live-write boundary. Use synthetic keys only
in isolated tests; do not access providers, provision real trust or sign reviews.
