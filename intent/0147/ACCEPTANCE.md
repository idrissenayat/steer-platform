# Development acceptance

- Real synthetic Ed25519 verification binds every current Critic report/run field.
- Wrong scope/provider/task/configuration/Builder, tampering and cross-profile proofs reject.
- Contrary native or signed context claims and identical task/run IDs fail closed.
- Exact chronology, activation, expiry and revocation are enforced through completion.
- Native Git preserves current report, selected history and source-pinned runner bytes.
- Configured missing/invalid proof cannot fall back; adverse Critic verdict remains blocked.
- Invalid startup paths/identities reject before source reads.
- Focused, type, architecture and full repository checks pass without weakened controls.
- All provenance, isolation, gate, release and live-use boundaries remain explicit.
