# Discover the permitted artifact manifest from Git

Explicit manifest replay works, but manually listing every artifact misses new
items. Discover eligible files from the repository's pinned tree while keeping
the selection policy explicit and preventing source-revision substitution.

Success means exact directory/filename selection, rejection of incomplete or
ambiguous inventories, no unsafe selected file modes, and inventory-driven
Git/Postgres reconciliation read through the authenticated browser fixture.

Do not broaden live permissions, enable writes to Git or treat absent files as
authorization to delete projections. Preserve current gates and operating-model
authority, existing bounds, and the pink/orange UI without unrelated changes.
