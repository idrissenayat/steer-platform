# Acceptance boundary

This increment exposes verified historical documents for a known recorded run
and a read-only comparison with a preserved editor snapshot. Complete historical
roles do not accept the Exam, grant current scope clearance, sign a gate or prove
that later human edits were agent-authored.

All-revision/orphan discovery, immutable save preparation/confirmation/start,
qualified records adoption, model-budget approval, live source/provider authority
and the real signed-in saved-repository acceptance matrix remain open.

No credentials are inspected, model calls paid, runtime Git writes enabled,
authentication bypassed, production migrated, gates signed or deployment performed.
Preserve signed artifacts, existing drafts and user-owned roadmap/outputs.
