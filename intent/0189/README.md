# 0189 — Direct review-record workspace

A read-only production workspace entry point for selecting a permitted exact Brief
revision and inspecting its recorded decisions/evidence without opening the full
Brief dialog first. This is not an actionable or assigned Inbox.

See [Brief](BRIEF.md), [Spec](SPEC.md), [Plan](PLAN.md), [Acceptance](ACCEPTANCE.md)
and [Evidence](EVIDENCE.md). No protected EXAM or approval artifact is changed.
Usage and boundaries: [Review workspace guide](../../docs/REVIEW-WORKSPACE.md).
