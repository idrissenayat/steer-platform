# Development acceptance

This is not a protected Exam or independent gate approval.

- Exact-content SHA-256, authenticated originator and supplied facts are retained.
- Correction changes the fingerprint; neither result claims saved or confirmed.
- Empty facts return specific omissions without invented answers.
- Nonhuman, ungranted, foreign-tenant, forged, oversized and expired requests deny.
- Freshness checks discard results after revocation, grant loss or identity switch.
- HTTP and MCP return the same contract; default startup denies unauthenticated use.
- Existing package/prototype/control/build checks pass; no protected changes.
- Forecast and next demonstrable journey increment are documented separately from
  provider/gate waits and remaining assurance obligations.
