# Development acceptance

These Builder checks are not an independent protected Exam or gate approval.

- [x] Official SDK v2 and protocol pinned; vendor import restricted to transport.
- [x] Discovery/input/output schema parity and canonical internal/HTTP dispatch.
- [x] Fixed-origin bearer-only profile; tenant/grant/identity, protocol and body
      denials; no cookies, legacy fallback, subscriptions or client authority.
- [x] Fresh authorization before calls and after async projection reads.
- [x] Eight actual concurrent requests, denied overlap capacity and truthful drain.
- [x] Official client across actual TLS/Keycloak/current Git, revocation/restore,
      HTTP parity and listener closure; browser regression passing.
- [x] Full checks, frozen install, production dependency audit and docs.
- [ ] Combined runtime mounting/resource coordination, OAuth onboarding, any
      future stdio/streams, durable workflows and real provider bindings.
- [ ] Independent gates, deployment/release and production outcomes.
