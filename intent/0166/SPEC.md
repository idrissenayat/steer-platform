# Spec

Reuse the existing native Git creation fixture and request-owned production writer
through a shared test harness; never seed the saved Brief/operation pair. Preview
then confirm exact bytes through the real Hono/shared tool path. Recover status
through a reconstructed API and use that authenticated request as the worker's
current receipt callback, not a copied receipt returned as authority.

Run the actual recorded-Brief workflow against the owned PostgreSQL projector pool.
Use a separate steer_app pool and curated reader through the same catalog and exact
Brief tools used by the work-list UI. Assert no record before projection, then one
exact revision/digest and original content after projection and reconstructed reads.
No extra Git mutation or ingestion event from status, replay or duplicate requests.

Exercise lost acknowledgement, human status-grant denial at worker time, projector
revocation, foreign tenant/unconfigured source and wrong revision/digest read denial.
History remains content-free. Test identities and full write-authority callbacks are
explicit synthetic doubles. Native Git commits, SQL, worker execution and tool reads
are actual. Do not infer browser interaction, live GitHub, gate clearance or real
member approval from this suite. Close only owned resources on success or failure.
