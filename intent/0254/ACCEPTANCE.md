# Acceptance boundary

Local synthetic authority/model responses and temporary native Git/SQL demonstrate
structural binding and integrated application behavior, not semantic quality,
production records adoption, provider authorization or real human acceptance.

I2/I5 advance only for read-only final edited-scope/disposition review. I1–I6 live
acceptance remains open. Exact save confirmation, destination/lifecycle/lineage,
immutable admission/start and the signed-in saved-repository journey are not
completed here. A read digest can never grant saving or serve as a gate signature.

Preserve signed documents, canonical Exam, actual drafts and user-owned untracked
files. No key access, model spend, real migration, runtime Git write, deployment,
release, deletion or authentication bypass.
