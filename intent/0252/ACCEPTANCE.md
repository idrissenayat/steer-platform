# Acceptance boundary

Development checks may demonstrate exact-byte reopening under synthetic current
identity/source authority and native disposable Git data. The actual React
component graph can establish controls, safe Markdown, no draft replacement and
content clearing. These checks are not visual browser acceptance or live human
save/reopen evidence.

I5 and I6 remain open until authorized saving and exact reopening are demonstrated
by a human in the real signed-in application with a real saved repository commit.
The read query grants no write, gate, lifecycle transition, records adoption,
model budget, provider access, deployment or release authority.
