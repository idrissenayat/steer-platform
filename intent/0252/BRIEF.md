# Intent Brief — Exact saved candidate reopening

## Problem and outcome

A human needs to inspect the exact Brief, Spec and Exam that a candidate bundle
contains at a selected saved commit, without losing current draft work or
mistaking candidate content for approved work. The existing Git reader has no
public tool or actual workspace view.

## Scope and boundaries

Add a reference-only, authenticated read query and exact-link view in the actual
Next application, with immutable-byte verification and safe failure clearing.
Use the existing pink/orange design, Markdown and same-origin transport.
Do not add writes, grant access, activate records, change signed documents,
call models, deploy, or claim live human acceptance. Save admission, receipt-link
generation and discovery are subsequent integrations.
