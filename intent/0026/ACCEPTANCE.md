# Development acceptance, not an independent Exam

| Requirement | Check |
| --- | --- |
| Requested pink/orange design | Existing tokens and reviewed desktop/mobile screenshots |
| Disabled unless explicitly configured | Public-view unit matrix and actual disabled Next.js instance |
| Native fixed-path, script-independent forms | Source guard and script-blocked real browser flow |
| Usable mobile/keyboard layout | 390 px no-overflow, visible control and keyboard focus checks |
| Automated accessibility | axe WCAG 2 A/AA and 2.1 AA checks on actual rendered page |
| Real identity/storage integration preserved | Native provider callback, Git revocation, encrypted sessions and logout |
| No false production/identity state | Preview notice, no invented user, default API remains closed |

Manual specialist accessibility, other browser engines, client hydration and
complete product UI are not accepted by these checks.
