bindings. It is not a public API/UI, combined-bundle proof, live model provenance,
accepted Exam, execution renewal or completed I1–I6 journey.

Combined snapshot/role verification, safe human lineage comparison, all-revision
discovery, final save preparation/confirmation/start and actual signed-in saved
repository acceptance remain open. Do not label edited human documents as agent
originals or infer success from an unavailable historical role.

No D1 adoption, live migration, credential access, spending, runtime Git write,
auth bypass, gate, deployment, release or destructive action is authorized. Preserve
signed documents, protected Exam, existing drafts and user-owned roadmap/outputs.
