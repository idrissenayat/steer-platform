# Acceptance boundary

Development checks must bind exact edited scope, corpus and profile to every batch;
preserve full source context and exclude inherited Exam/role history; capture the
actual SDK request before transport and validated response before return; reject
invented citations, changed source/profile, invalid provider output and lost
acknowledgements; and preserve incomplete coverage after aggregation.

The previous Architect/Test Agent path must remain compatible. A recorded scope
exchange can be reverified without keys or network. Synthetic findings and callback
acknowledgements do not prove semantic accuracy, independent review, durable SQL
ownership, real provider authority, paid budget approval or usable end-to-end UI.
This is not the canonical Exam or any gate signature.
