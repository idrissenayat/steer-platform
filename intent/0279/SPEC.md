# Intent 0279 specification

1. One trusted read-only source-review request may own verified immutable corpus
   content. The initial collection still verifies exact head, full tree, consumed
   bodies/digests, product/lifecycle selection and current permissions. Capture is
   private; HTTP input, caller-created evidence and other requests cannot supply it.
2. Record every consumed path, including candidate pointers, manifests and Exam
   files excluded from semantic Brief/Spec assessment. Recheck all consumed grants
   at the end of initial collection, before each reuse and after the caller's last
   read-only work. Recheck all observed roots, including excluded product roots.
3. Each reuse checks current caller and inventory authority around asynchronous
   head, source-grant and selection reads. Permission revision, selections, head,
   reader binding and installed read/authority methods must stay exact. No stale
   fallback, permission cache, grant lease or reduced identity-head freshness.
4. Unknown, missing, inaccessible or corrupt source coverage stays on full reads
   and cannot silently become complete within one session. Verified whole-source
   content exceeding a semantic batch/context limit keeps its exact coverage gaps;
   the existing batch planner remains responsible for its assessment.
5. The private session encloses only read-only development source review. Keep both
   exact draft reads and provenance callbacks, and keep ordinary corpus collection
   for scope/assessed preparation. Never span originals/admission, scheduling,
   model dispatch, Git writes or publication. No deadlines are increased.
6. Four bounded session slots, closure and monotonic deadlines suppress late output.
   Timed-out/abandoned work owns its slot until dependencies drain. Parallel reads,
   swallowed failures, no reads, escaped readers and nonvoid authority callbacks
   cannot return verified success. No cross-request captured state.
7. Run current-authority/lineage/closure negatives, affected SQL and the same joined
   34-source workflow before performance claims. Preserve six synthetic model
   reservations, separate Architect/Test Agent work, one confirmed original/native
   commit, lost-acknowledgement recovery and exact reopen. Build and broad tests are
   engineering evidence, not real signed-in UI acceptance.
8. Preserve user files, protected signatures/Exam, auth, D1 inactivity and live
   spending/provider/write gates. No real model requests, credentials, deployment,
   release, deletion, policy adoption or runtime GitHub writes.
