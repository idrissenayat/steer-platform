# Intent 0270 — Verified publication to draft lifecycle

The confirmed package journey can verify a saved Git receipt and execution
checkpoint without applying the private draft's publication-retention transition.
Close that engineering gap through an explicit records action with original-bound
evidence, a required trusted clock and unchanged fail-closed authority boundaries.

Deliver an uninstalled recorder, owned API composition, negative contract tests and
a joined disposable integration. Preserve the actual application's authentication,
pink/orange design, signed sources, existing drafts and user-owned files.

This does not adopt D1, define a real clock authority, activate records, authorize
model/provider usage, expose a new browser tool, sign a gate or delete anything.
See [specification](SPEC.md), [guide](../../docs/CANDIDATE-PUBLICATION-RECORDS.md)
and [evidence](EVIDENCE.md).
