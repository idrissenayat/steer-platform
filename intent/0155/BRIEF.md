# Brief

An author needs to see what they reviewed, where it could go, and whether a prior
operation has a recorded result. Preview, local confirmation, Git persistence and
human gate signatures must not be conflated. Implement that interface now, without
waiting on or bypassing the missing live writer/governance approvals.

Preserve STEER's pink/orange design, Next.js foundation, normalized identity and
current server authorization. No new hosting, identity provider, model call,
browser persistence, provider access or paid resource is required.
