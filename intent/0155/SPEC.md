# Spec

After an authenticated preview and a current read-only destination observation,
allow explicit choice among configured canonical Brief paths. A local checkbox
acknowledges the displayed content for exactly that organization, subject,
repository, branch, path, observed head, content digest, template, observation and
session display expiry. It is not an approval, operation, save or signature.
No path is preselected. Different preview/destination/session props remount the
review; path changes clear acceptance. Hiding, navigation and the existing
15-second destination display expiry clear review and status details. Rechecking
the destination creates a fresh observation and requires a fresh review.

The GitHub save button is permanently disabled and has no dispatch handler.
Explain the missing governed evidence selection, review provenance and complete
action-time authority. The browser receives no authority factory or save endpoint.
Server authorization remains decisive even if someone changes their local DOM.

Offer a separate, optional previous-save status section for the selected scope.
The author supplies the original UUIDv4 operation ID; never generate a new one.
Only an explicit click makes one fixed HTTPS same-origin, no-store status query.
Reuse the bounded read transport, with no command endpoint, automatic polling or
retry. Validate the portable strict result contract and compare organization,
repository, branch, path, operation and authenticated display subject. Wrong-scope,
malformed, expired, failed or late responses must not retain prior receipt details.

Represent not-found, unknown, pending, conflict and committed distinctly. Absence
does not prove failure; uncertain operations must not be resubmitted. A committed
receipt is labeled as a prior recorded operation, never proof that the current
draft is saved. Display its revision, content digest, original expected head and
path as text. Never claim a gate signature from a save receipt.

Use accessible labels, keyboard controls, status regions, existing theme tokens
and responsive layout. Preserve original facts and exact preview bytes while
reading destinations/status. No local/session storage, external links or telemetry.
