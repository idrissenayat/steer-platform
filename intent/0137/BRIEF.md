# Brief

Advance the gate verifier by checking the identity/session evidence whose digest
is carried in a signed provider gate record. A matching account name or recorded
hat is not sufficient evidence that the same identity authenticated that session.
Join a scoped identity-service attestation to the actual historical/current Git
hat checks without persisting access tokens or enabling a gate/write.

This is a closed development profile. It neither converts the existing commercial
openai-codex approval nor asserts that a real identity service issues these receipts.
