# Development acceptance

Not a protected Exam or independent gate decision.

- A failing regression demonstrates expiry after individual verification.
- All verified key, current-role and qualification expiry/revocation bounds apply.
- Every signer remains valid at the same final evaluation instant, or collection denies.
- Exact nanosecond boundaries distinguish one nanosecond before/at/after expiry.
- Properly verified historical signatures survive natural later login expiry.
- Immutable results retain mandatory revalidation and never satisfy write authority.
- Reuse performs actual source reads and rejects a newly revoked role.
- Existing native Git, cryptography, head/actor/time and real stalled-read tests pass.
- Full repository checks pass before publishing; protected artifacts stay untouched.
