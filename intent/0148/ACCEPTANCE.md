# Development acceptance

- Shared discovery, OpenAPI, HTTP and MCP describe one read-only tool.
- Missing grants, wrong tenant, caller-selected targets and agent hats deny before I/O.
- Configured scope is canonical, unique, bounded and independent of projections.
- Head output follows actual changing native Git through the read-only adapter.
- Revocation, identity switching, expiry, malformed output and late observations deny.
- Startup is lazy and opt-in; real grants, keys, providers and writer stay unchanged.
- Focused and full repository checks pass without weakened architecture controls.
- Evidence distinguishes local development from UI integration and live enablement.
