# Development acceptance

Not a protected Exam or independent gate decision.

- Actual canonical signer verification and policy evaluation span Gate 1 through target.
- Every policy/review source is exact-head, path/scope/hash-bound and strictly parsed.
- Actual source digests feed the evaluator; callers cannot inject facts or source paths.
- A satisfied target cannot hide a failed prerequisite; send-back/declined stay adverse.
- Missing build/domain, unresolved findings, stale or inconclusive reviews stay blocked.
- Full source target mismatches, duplicate/unknown JSON and corrupted bytes reject.
- Final head, actor, clock, expiry and shared signer validity checks remain mandatory.
- Real stalled work retains single-flight ownership and draining shutdown without late reads.
- Nested results are immutable and never satisfy the writer-authority schema.
- Native Git, genuine ephemeral signatures and all relevant repository checks pass.
- Existing protected records, approval formats, runtime scopes and frontend stay unchanged.
