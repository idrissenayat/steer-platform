# Spec

- Bind exact UTF-8 source, clarification, home and current Brief/Spec hashes into
  a distinct scope fingerprint. Reject malformed Unicode; never normalize bytes.
- Compare every final save reference, human/draft revision and destination/head.
  Identify late completion for an older revision or different workspace without
  applying it to newer edits. Equality is not authorization.
- Wire cumulative review invalidation into the actual editor. Generated scope is
  not cleared by the earlier interview review; undo cannot restore confirmation.
  Preserve originals and historical reasons. Edits trigger no network or storage.
- Build bounded evidence from declared authorized inventory without lexical
  filtering. Verify SHA-256 and Git blob hashes, preserve whole source context,
  and expose limits/gaps. Validate exact UTF-8 citations and source/config bindings.
  Missing/unassessed/abstained evidence remains incomplete; semantic correctness
  and completeness of the caller's inventory are separate acceptance.
- Plan fenced ownership, pre-dispatch-only lease takeover, reservation reuse,
  one-way dispatch and result checkpoints. Unknown outcomes cannot automatically
  retry. The future adapter must atomically commit claims/reservations and enforce
  CAS; these pure functions cannot create dispatch permission.
- Plan exact new-candidate, pre-pull-revision and amendment file sets, hashes,
  pointers and receipts. Do not generate canonical Spec/Exam or gate write paths.
  Preserve explicit subject/service attribution without claiming signatures.
- No real storage, model, worker or Git adapter activation. Preserve signed
  requirements and the existing accepted records policy.
