# Brief

People need to see what happened after submitting an intent: whether the agent is
working, needs clarification, has prepared candidate documents or needs attention.
Refresh and recovery must not cause another model dispatch or confuse an older
generation with newer human text.

This increment supplies the read side of that journey. The actual shared HTTP tool
reads encrypted SQL originals, steps, results and observations under current human
and records authority. It verifies recorded exchanges before returning candidate
content. Neither a workflow query nor retained bytes alone establish permission.

Workflow submission, editor progress/result integration, owned-draft discovery,
full-source semantic review and real activation remain separate remaining work.
No live model call, records-policy adoption, database migration or Git save is
authorized by this implementation.
