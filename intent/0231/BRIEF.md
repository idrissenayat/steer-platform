# Brief — Working-draft discovery and recovery

A person returning to STEER needs to find an acknowledged draft and the work
already recorded for it. Remembering a technical reference or creating another
intent to regain progress undermines reliability.

Add owner-scoped discovery to the existing editor. List bounded metadata only,
preview content on request, preserve current text until explicit replacement, and
read the retained run for the exact restored revision before any execution action.
Unavailable access must not be presented as no drafts. Keep the pink/orange design.

This development increment grants no records-policy adoption, runtime activation,
paid model usage, Git saving, gate signature or release.
