# 0264 — Diagnose preparation without captured original input

A recorded preparation request must not disappear from a human's understanding
just because its original-input capture was interrupted. Add read-only diagnostics
to the actual draft run-history panel. Distinguish observed metadata from verified
content, execution outcome and permission to retry, without starting replacement
work, exposing source text or weakening records/tenant boundaries.
