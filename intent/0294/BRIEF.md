# 0294 — Forward proven corpus reads through the candidate catalog

Reduce duplicate caller validation in source review without weakening the current
authority, source-grant, deadline or recovery checks. This is a bounded C22
performance increment, not a completed checkpoint or a live-provider activation.

Only privately proven argument-independent reads can use the direct forwarding
path. All ordinary readers retain full policy checks. The parent catalog must
retain admission until actual child callbacks drain, even after a timeout.

No model spending, credentials, records adoption, runtime GitHub writes, gate
signature, deployment, release or user-data deletion is authorized here.
