# Specification

1. Keep all 30 exact LIFECYCLE-GRAPH-NEGATIVE IDs. Map 27 ordinary failed-run cases;
   leave reference-missing, raw-grant-missing and malformed-raw-grant uncovered.
   Preserve the complete independent 4,036-ID catalog and frozen source pins.
2. SOURCE-MAP.json identifies each frozen mutation and corrected representation,
   construction scope, expected state or reason it remains unmapped. Seal this
   source map with the execution hook sources in each new report.
3. Every hook first runs the complete same-class control through 0061: two copies,
   three protected actions, correct 90-day synthetic boundary and full evidence
   digest. Then execute the actual adapted negative with typed zero effects.
4. Active hold uses chronological committed/terminal/hold events and an independent
   signed active state, producing retained-on-hold. Overlapping/conflicting state
   denies. Do not mistake malformed chronology for successful hold enforcement.
5. Re-sign stale inventory, partial receipt, wrong copy/key/provider selectors,
   missing aggregate receipt set, early tombstone receipt, losing CAS and invalid
   human schema. Resource selectors moved into the shared provider resource proof;
   receipt evidence binds them by digest. Do not invent obsolete receipt fields.
6. Preserve old downstream bytes for restored-version and inventory set races,
   copy/action/receipt transplants, omissions and ordinary-domain impersonation.
   Signed empty aggregate set and absent aggregate bytes are distinct cases.
7. Bind exact policy/Exam changes through an altered action context digest while
   the graph independently derives its authorized context. Reject provider receipts
   before notBefore or after key expiry using their recordedAt timestamps.
8. The original-era graph pins provider registry configuration and has no caller
   registry field. Reject injected changed registry bytes via its closed envelope.
   This does not claim current-registry installation or live key-custody coverage.
9. Expose only a closed negative-kind adapter from the shared fixture module,
   never a signer or caller mutation callback. Unknown/raw/reference kinds throw
   at fixture selection and are not registered as execution hooks.
10. Save fresh quick/full reports and rerun focused, repository and separate full
    checks. Each mapped ID records two actual observations, not a label-only count.

The synthetic clock and signatures are not real retention observation, human
approval or deletion. Remaining class/boundary cases, raw/reference controls,
migration matrix, schema reconciliation and independent/protected review stay open.
