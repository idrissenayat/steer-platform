# Brief

The reference content, revocation and action profiles must participate in the
actual composed lifecycle verifier, not exist only as isolated passing checks.
Disposition must remain blocked until the same exact record/version/reference
set is retained, revoked, removed and independently authorized for every copy
and a durable named tombstone.

Reuse the complete existing verifiers through a separately trusted runtime.
Keep original contracts, frozen review artifacts and zero-effect boundaries.
