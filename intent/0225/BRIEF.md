# Brief

Give the actual editor a server contract for preserving and reopening exact draft
content. A created reference is not preserved text, a preserved draft is not a Git
save, and conflicting or uncertain writes must not overwrite a human's newer work.

Connect existing encrypted lifecycle/revision stores to the shared API tool layer,
with current human/owner/product/repository checks. Keep real records activation
separate; do not create an alternate preview, weaken authentication, or call models.
