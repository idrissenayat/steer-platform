# Brief

Compose 0182's recovery scheduler into the existing authenticated runtime with an
explicit failed-run profile and separately owned factory. Require exact scope,
current signed identity/Git membership and draining lifecycle without inferring
recovery from ordinary dispatch, saving, projection or browser configuration.

Join that runtime to actual local Temporal/Git/PostgreSQL recovery while keeping
synthetic issuer and receipt-provenance limits explicit. Actual Keycloak recovery
identity and approved live bindings remain separate acceptance work.
