# Brief

The signed records policy requires a qualified owner decision for exact reference
revocation with retained verification evidence. Existing disposition and hold
profiles cannot express that decision truthfully: a live reference or active hold
must not be falsely marked cleared, and an approval to revoke a reference is not
an erasure grant.

Create a closed, explicit reference profile using all existing complete human
proof checks. Bind the actual evidence identifiers now; exact content/event/history
composition follows. Preserve frozen schemas and existing profile policies.
