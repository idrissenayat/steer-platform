# Development acceptance checklist

This is not a protected Exam or gate approval.

- [x] Fixed trusted repository context; no spoofed/foreign/unverified display scope.
- [x] One-time permitted catalog discovery, no manual source fields.
- [x] Strict exact-reference reads and unavailable/stale/foreign failures.
- [x] Rendered source without script execution or remote media/navigation.
- [x] Keyboard dialog, focus return, desktop/mobile visual inspection and axe checks.
- [x] Revocation, lifecycle/expiry cleanup, no browser storage/polling or writes.
- [x] Shared canonical contracts and architectural boundaries retained.
- [x] Full root check and frozen install.
- Candidate publication: exact remote equality is verified in the task handoff.

Recorded outcomes and any limitations belong in EVIDENCE.md. Completion of this
checklist cannot establish the remaining intent/0003, Gate 2 or release criteria.
