# Development acceptance

Not a protected Exam or independent gate decision.

- Real provider signature verification and both exact Git source reads are required.
- An authentic provider claim cannot supply an absent, inactive, foreign or agent hat.
- Historical authentication/signing and current grant validity use exact UTC bounds.
- Current revocation and moved heads cannot reuse a prior successful observation.
- Corrupt/mismatched/oversized sources and caller-selected extra source facts deny.
- Provider-only results stay distinct and both methods share deadline/ownership.
- Native Git demonstrates different historical/current grant bytes and revocation.
- Outputs remain non-authorizing; no existing approval, protected file, runtime
  profile or live provider permission changes.
