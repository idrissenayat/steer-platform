# Development spec

- Obtain a fresh service token from this run's disposable Keycloak client through
  the existing pinned HTTPS transport. Do not extend token or gate-evidence lifetimes.
- Validate issuer, audience, client, signature and principal through the existing
  OIDC adapter. Resolve current observer membership from a separate exact native
  Git grant file through the actual read-only App adapter on every authentication.
- Require the current agent's explicit gate.observe grant and no human hats. The
  successful browser collection must use neither the direct-principal callback nor
  the synthetic identity JWKS port.
- Committed observer revocation, removed grant and invalid token each deny without
  retained assessment or mutation. Restore a genuinely verified agent before
  testing the independent current-human revocation boundary.
- Preserve the exact UI, manifest, status/reconstruction, single-attempt and
  cleanup checks. No successful full-authority callback, real trust root, provider
  access, paid usage, production configuration or protected artifact is introduced.
