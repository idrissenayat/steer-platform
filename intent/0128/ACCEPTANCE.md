# Development acceptance

Not a protected Exam or an independent gate decision.

- Exact source commit, record digest and complete governed artifact set are bound.
- Missing, stale, changed, corrupt or unauthorized source cannot yield a bundle.
- Returned bytes are immutable copies with no unverified adapter fields.
- Legacy observation output and shared shutdown/single-flight behavior remain.
- Expiry during the final head read denies the result.
- A send-back bundle is possible but never gate approval or write authority.
- Real reader composition uses isolated synthetic read-only transport.
- Full repository checks pass; no public API, UI or runtime writer is enabled.
