# Evidence

## Implemented scope

A separate disposable Chromium context drives production authoring, exact local
review and submission through the actual HTTPS gateway and identity runtime. The
current human authenticates with local Keycloak and encrypted PostgreSQL sessions.
Native Git supplies the pinned policy manifest and current membership; the App JWT
is cryptographically checked by a no-fallback synthetic provider transport.

The held path receives no successful full-authority callback. A policy match remains
a denied save with zero write-token requests, no Brief/marker and unchanged Git HEAD.
Reconstruction and manual status must report not-found; observer loss and committed
human revocation deny again. Refreshing destination/review must not unlock a second
submission. Historical gate signers, trust roots, qualifications, normalized reviews
and the observer remain synthetic, not independently approved real evidence.
