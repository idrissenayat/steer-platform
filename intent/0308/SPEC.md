# 0308 specification

- Native application readers use the owned batch corpus graph; foreign adapter
  implementations retain the existing compatible collector. Selection is by
  constructor identity, never a browser flag or fallback after a native failure.
- Current source review retains aggregate inaccessible/unresolved/missing-source
  warnings and full permitted Brief/Spec bytes. It does not infer newness. Retained
  history stays strict; no incomplete historical verification is introduced.
- Preserve source IDs, target IDs, selection fingerprint, candidate/amendment
  integrity, hidden Exam exclusion and the existing evidence/envelope contract.
- Repeated read-only evidence projections share bytes only within their invocation;
  current caller, head, selections and every consumed path close the whole phase.
- No effects are moved inside that phase. Actual cancelled callbacks retain
  admission until drained, and shutdown drains the graph before owned resources.
- Verify exact valid projections against the existing collector, incomplete and
  revoked inputs, owned cancellation, and authenticated native save/reopen. Report
  actual whole-action attempt counts without treating this portion as full C22.
- Keep SDK/storage composition at the existing API runtime entry point and use
  declared data exports, not cross-package source paths. The canonical Node-only
  data codec may use structural equality; this grants no other layer that import.
