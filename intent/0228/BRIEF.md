# Brief

After a person's exact draft and development input have been recorded, the API must
be able to start that work without confusing a scheduling acknowledgement with
generated documents. A lost response or repeated click must address the same
operation, not silently create another run or pay for another model request.

This increment connects a shared command to existing encrypted source/operation
records and the actual Temporal client. Fresh source, identity, records and
execution authority are required. History readback binds the acknowledgement to
the expected original reference; candidate content stays in encrypted SQL and is
retrieved through the separate 0227 query.

Preparing/admitting the source record from the editor's reviewed draft remains
upstream work. This command cannot infer human direction, authoritative search,
approved budget or records-policy adoption from a reference or tool grant.
