# Development acceptance

Not a protected Exam or independent gate approval.

- Signed-in workspace offers a one-question interview, not eight simultaneous fields.
- Incomplete preview exposes missing fields; correction invalidates old fingerprint.
- The response must match display identity and exact content SHA-256.
- Saved/confirmed/authorizing and foreign/malformed/late responses deny.
- Native keyboard preview and correction focus work; mobile has no horizontal overflow.
- Rendered links/HTML stay inert; browser stores no draft in local/session storage.
- Committed grant denial, page lifecycle and expiry clear unsaved facts/results.
- Local invalid input preserves facts without submission; output has honest limits.
- Browser integration and repository controls pass without relaxed assertions,
  production bypasses, real providers, gate signatures or frozen-source changes.
