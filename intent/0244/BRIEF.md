# Brief

The reference-only scope workflow needs a trustworthy preparation path from the
human's saved draft and current permitted repository sources. Browser-supplied
document bytes, batch lists, profiles or budget claims must not become worker input.

Prepare one exact durable review, preserve its encrypted input, and return an
honest metadata receipt. Repeated requests must recover the same review. Human
edits, incomplete search, lost acknowledgements and authority changes must not
produce false readiness or uniqueness. Keep existing authenticated surfaces and
all live-activation boundaries unchanged.
