# Read-through provider proof sources

The 0130 signature primitive accepts a selected trust snapshot and expected facts.
Before writer composition, connect it to authenticated current Git reads with
exact file/revision/hash pins, no stale fallback and bounded owned work. A record
changing or access being revoked must discard the observation.

Do not confuse retrieving a public key from Git with approval of that key. No
production trust source, provider binding, human signature or writer is installed.
