# Brief

A prepared review needs an authorized start path that cannot substitute source,
silently retry paid work or report completion from an unrelated workflow. A lost
response must recover the same retained workflow, not create a replacement.

Expose exact-source scope start/recovery through the shared authenticated API.
Recheck current human, records, source and execution authority around scheduling.
Keep workflow acknowledgement distinct from verified findings, semantic quality,
permission to draft/save and gates. Preserve current authentication and live limits.
