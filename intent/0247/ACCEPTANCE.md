# Development acceptance boundary

- Exact latest owner draft can discover captured scope references through the
  actual API contract without keys, encrypted content, model calls or reservations.
- A bounded stable cursor traverses distinct captured originals for one draft.
- Denied/foreign/stale/held/discarded/published/expired inputs do not disclose
  references or become an empty/no-duplicate assertion.
- The actual React editor can find and read completed findings without a prepare
  or start call, including while model-use capability is disabled.
- Pending recovery is explicit and reuses the exact reference. Loss, source drift,
  unknown replies and closure cannot create replacement work or stale findings.

These are development checks with synthetic authority/provider HTTP and disposable
database fixtures. They are not independent semantic evaluation, actual browser
visual/accessibility acceptance, live persistence installation or I6 acceptance.

D1 remains unsigned/inactive; the first-test model budget remains unapproved.
No new credential, auth bypass, runtime Git save, gate, deployment or release is
authorized. Preserve all signed source hashes and unrelated user files.
